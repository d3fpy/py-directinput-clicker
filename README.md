# py-directinput-clicker

A simple Python keyboard auto-clicker designed for games and applications that utilize DirectX / DirectInput.

## Quick Start

1. Install dependencies:
   ```bash
   pip install keyboard pydirectinput
   ```
2. Run your terminal or IDE as Administrator.
3. Start the script.
4. Switch to the game window and press F1 to toggle the E key spamming.
